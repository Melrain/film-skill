# 跟拍续写剧本

## 何时使用

视频解析已成功，需要**无感续写**成可跟拍剧本/场次描述，并挂到文字资产卡（先描述、点选再出图）。

## 目标输出

- 在解析镜号基础上续写：场次目标、人物行为、对白（可精炼）、画面提示句
- 人物名、服装、空间关系与解析结果连续，不突然换设定
- 每段描述应能直接变成「文字资产卡」正文（描述优先，不在此步强制出图）

## 步骤

1. 读取解析镜号列表，提取人物、场景、冲突或卖点。
2. 按镜或按场输出续写；保持时间顺序。
3. 每段写清：谁在做什么、镜头大致怎么看、必要对白。
4. 结尾给「下一段可接」的钩子（一句即可），方便用户改稿。
5. 若某镜信息不足，标明「待补」而不是虚构。

## 硬约束 / 禁止

- 禁止无视解析结果另起炉灶。
- 禁止加入解析里没有的关键道具/身份，除非标注为创作增量。
- 禁止长篇小说腔；服务短视频/跟拍节奏。
- 失败时停在当前步并说明缺什么，便于重跑。

## 输出格式

```text
## 人物与连续设定
- …

## 续写
### 场/镜 1
- 描述：…
- 对白：…
- 画面提示：…

### 场/镜 2
…
```

## 质检清单

- [ ] 与解析镜号可对齐（可多镜合并为一场，但勿丢关键镜）
- [ ] 人物称谓前后一致
- [ ] 每段描述可单独拿去出图或拍摄
- [ ] 无空话段落
