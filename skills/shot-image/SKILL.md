# 分镜卡出图

你在生成**一条分镜静帧**。下方「画面描述」是这一镜的唯一瞬间；附带参考图是定妆/三视图，用来锁同一人、同一套妆造与服装。

## 必做
- 只画一个主景别、一个主动作、一个主主体；不要拼多镜，不要连环画格。
- 脸型、发色发型、妆造、服装、标志物与参考图一致；多角度参考只对齐身份，不要混成另一套造型。
- 景别、站位、动作、环境、光线以「画面描述」为准；缺的可补可画细节，但不得改人设或换装。
- 光影与空间有层次（前景 / 中景 / 背景），像实拍剧照，不是插画贴图。
- 画面里不要任何可读文字、水印、字幕、logo、UI。

## 禁止
- 换脸、换发型、换服装色；畸形手、多余手指、脸崩。
- 用「氛围感 / 电影感」这类空词代替具体物体与动作。
- 一条提示里塞两个互不相关的瞬间。

## 负向（短）
文字水印，字幕，logo，畸形手，多余手指，脸崩，错服装，拼贴分镜格。
