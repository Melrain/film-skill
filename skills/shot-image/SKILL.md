# 分镜卡出图

## 何时使用

文字资产卡已有镜头/场次描述，用户点击该卡**卡内出图**（不旁挂独立 image 节点）时，把描述收成可生成的画面提示。

## 目标输出

- 一条（或少量变体）生成用提示：主体、服装、动作、环境、景别、光线
- 锁定与上游一致的人物外观线索（发色、服装色、标志物）
- 中文主提示即可；若宿主需要英文，提供对照短句，勿两套互相矛盾

## 步骤

1. 从卡片描述抽出：谁、在哪、做什么、情绪落在脸上/手上的证据。
2. 补齐景别与机位（特写/中景/全景等），只选一个主景别。
3. 写出服装与道具的可画细节；禁止抽象风格词代替物体。
4. 注明光线与背景层次（前景/中景/背景各一句内）。
5. 给出「不要出现」的短列表（文字水印、多余肢体、错服装），保持简短。

## 硬约束 / 禁止

- 禁止换掉上游已锁定的人物关键外观。
- 禁止一次提示塞多个不相关镜头。
- 禁止输出假分辨率/假模型跑分。
- 点哪张卡出哪张；提示只服务当前卡。

## 输出格式

```text
## 提示词
…

## 锁定外观
- …

## 负向（简短）
- …
```

## 质检清单

- [ ] 提示能让人画出与描述同一瞬间
- [ ] 外观锁定与上游不冲突
- [ ] 只有一个主景别、一个主动作
- [ ] 负向列表短且具体
