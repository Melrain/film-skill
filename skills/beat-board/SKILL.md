# 分镜节奏法（拆文本分镜）

把剧本/场次拆成宿主可落库的 **JSON rows**：每一行是一个可拍、可出图的瞬间。优先写 `visualDesc`，不要只交 markdown 节拍板。

## 目标

- 约 6–10 行（有参考片跟拍时：镜数与时长对齐原片）
- 每行一个主景别、一个主动作、一个主瞬间
- `visualDesc` 必须可直接交给下游出图：景别 + 谁在哪做什么 + 服装或光线（可再补一件可画道具）
- `characters[]` 必填：出镜名与上游「人物 / 已绑定妆」称谓**逐字一致**；空镜写 `[]`

## 步骤

1. 标叙事拐点：开场钩子、冲突、反转、落点/CTA；拐点必须有对应行。
2. 按拐点成行；同一连续动作可合并；台词段落或机位大变则拆开。
3. 每行只写看得见的证据，禁止「很有氛围 / 情绪爆发」这类空词独自成句。
4. 对白写进 `dialogue`（可空）；不要把对白塞进 `visualDesc` 当字幕画面。
5. 自检：只读 `visualDesc` 能否在脑中画出同一静帧；人名是否都能在上游人物表对上。

## 硬约束

- 禁止另起人物名或换装换脸；已绑定妆的角色必须锁同一套妆造与服装线索。
- 禁止假图 URL、假精确帧时长；时长用上游已有或 2s–5s 量级短串（如 `3s`）。
- 禁止一行塞多个不相关瞬间；禁止只输出 markdown 列表。
- 服务短视频/跟拍节奏，拒绝舞台说明腔与影评腔。

## 输出（唯一有效）

```json
{
  "rows": [
    {
      "shotId": "S01",
      "duration": "3s",
      "visualDesc": "近景 · 林小满抬头望向车窗 · 湿发短外套，车厢冷白顶光",
      "dialogue": "",
      "sceneNo": "场 1",
      "characters": ["林小满"]
    }
  ]
}
```

`visualDesc` 推荐写法：`景别 · 主体动作（含环境） · 服装/光线`。

## 质检

- [ ] 拐点都有行；无空话行
- [ ] 每行 visualDesc 含景别+动作+服装或光线
- [ ] characters 齐全且与上游称谓一致
- [ ] 无假链、无纯 markdown
