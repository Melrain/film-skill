# 导演镜头（每次只用一条）

这些是可迁移的拍摄方法，不是成片分镜。用来改默认的机位、光、剪辑和提示口气。不要复刻任何影片里的具体镜头、台词或情节。

| id | 导演 | 这一条镜头在管什么 |
|----|------|-------------------|
| spielberg | 斯皮尔伯格 | 先给反应再给揭示；家庭利害要看得见；奇观从人的脸进入 |
| hitchcock | 希区柯克 | 观众知道的比角色多；视线与门窗制造窥视；信息晚给，镜头少晃 |
| kubrick | 库布里克 | 对称与一点透视；冷、正式、距离感；揭示之后再切反应 |
| kurosawa | 黑泽明 | 天气参与戏剧；群体在同一空间里分出主从；动作有明确方向 |
| scorsese | 斯科塞斯 | 城市能量和内疚；旁白可以带，但画面必须自己在坠落 |
| fellini | 费里尼 | 梦的逻辑、游行式人群；怪诞里留温柔，不要只堆奇观 |
| bergman | 伯格曼 | 脸的特写承担戏剧；留白和沉默比运镜重要 |
| tarkovsky | 塔可夫斯基 | 长镜头里的时间；水、火、风是事件，不是装饰 |
| wong | 王家卫 | 窄空间、霓虹实用光、错过；慢下来的是告别动作，不是整段炫技 |
| nolan | 诺兰 | 高概念要能被一个物理规则讲清；大场面仍回到人的选择 |
| villeneuve | 维伦纽瓦 | 巨物、雾、几何；安静和低频比台词响 |
| fincher | 芬奇 | 外科式控制；青橙关系克制；恐惧来自程序，不来自乱晃 |
| refn | 雷弗恩 | 色块、对称、慢凝视；暴力要短，前面留足静止 |
| bi-gan | 毕赣 | 雾、小镇、超长镜头里的梦与记忆回环；诗意旁白不能代替可见动作 |

未点名时不要使用本表。按本片类型自己定：机位倾向、光的逻辑、调色锚点、剪辑疏密、表演尺度。
