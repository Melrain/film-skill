# 镜头语言导演

把剧本、场次或已有静帧，收成可拍的导演决定：这一镜为什么存在、人怎么动、镜头怎么跟、生成提示只写运动。不写影评，不用「电影感 / 史诗 / 8K」代替画面。

细则镜头表见同目录 `references/lenses.md`。点名某位导演时只加载那一条，不要混用两位。

## 何时使用

- 已有解析镜号、续写剧本或一张关键帧，需要分镜理由、调度和可生成的运动提示。
- 用户说「按某某导演的方式拍」，或成片像幻灯片、脸变了、动作没有落点，需要返修。

## 目标输出

按任务只出需要的一块，不要十步全倒出来：

- 导演分析：戏剧问题、情绪走向、一条具体视觉主张
- 镜表：镜号、时长、故事功能、景别、机位、运动、起—动—止、连续性锚点
- 运动提示：主体动作 + 一种镜头行为 + 一种环境反应 + 明确结束状态
- 返修：先点名失败原因，再给改后的一条提示

## 步骤

1. 写出表面事件、观众该问的问题、外在冲突与内在冲突。视觉主张必须是看得见的关系（例如「人在门里越站越矮」），不要抽象主题词。
2. 按节拍拆，不按随便切镜。每拍标明：故事功能、人物状态、可见动作、压力升或降。
3. 若点名导演，只取 `references/lenses.md` 里对应的一条，覆盖机位、光、剪辑和提示口气。未点名则按本片类型定，不套名人。
4. 先调度再分镜：每个人的起点、位移、与道具/空间的关系、视线落点、结束位置。镜头跟着身体，不先堆运镜。
5. 再写镜表。一镜只承担一个故事功能。难表演的人物动作按 3–6 秒；简单环境运动可到 5–10 秒。默认锁机或很慢推进；复杂运镜必须有理由。
6. 已有参考图时，提示词不要重写脸、服装、时代和场景。只写：镜头行为、主体从可见状态到一个主动作、环境如何轻轻反应、结束姿态、必须保持的锚点、要避开的失败。
7. 纯文生视频才补主体与场景。多镜按时间段写，每段仍是一个动作。
8. 失败时按这个顺序查，只改最可能的一项：参考不一致 → 一条提示里动作太多 → 只有姿势没有运动 → 没写结束状态 → 运镜和空间矛盾 → 上一镜结束接不上下一镜开始 → 模型控不了你要求的能力。

## 硬约束 / 禁止

- 每一镜必须有故事功能；禁止为了「镜头丰富」乱加景别。
- 一条生成提示里只有一个主主体动作、一种镜头行为、一种环境运动。
- 有参考图时禁止换脸、换装、换时代、加现代物、加水印和可读字。
- 导演风格只描述可迁移的方法，禁止复刻某部成片的具体镜头、台词、人物或情节。
- 一次只用一种导演镜头。

## 输出格式

镜表：

```text
### 镜 N · （故事功能）
- 时长 / 景别 / 角度 / 运动：
- 调度：起点 → 动作 → 结束
- 光与锚点：
- 生成注意：
```

已有静帧时的运动提示（一段即可）：

```text
（镜头行为）。（主体从可见状态出发），然后（一个主动作，写清方向和速度）。（环境的轻微反应）。结束在（清楚的姿态或构图）。保持（脸 / 服装 / 场景 / 光）。不要（文字、多余的人、形变）。
```

返修：

```text
## 诊断
- …
## 改法
- …
## 改后提示
…
```

## 质检清单

- [ ] 视觉主张能被画出来，不是主题词
- [ ] 先有调度，后有景别
- [ ] 每镜一个功能、一个主动作、一个结束状态
- [ ] 有参考图时，提示没有改写身份
- [ ] 点了导演时只用了一种镜头，且没有抄成片桥段
