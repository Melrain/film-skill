# 短片视频提示

把一个短片意图写成可直接交给视频模型的一条提示。骨架固定为五段，顺序不要打乱。服务画布上已有的人物锁、场景和镜号；缺的用合理假设写明，不要盘问超过三个问题。

## 何时使用

用户要一条可粘贴的短片 / 图生视频提示：单镜变形、多镜叙事、情绪短片、产品或氛围镜头。目标模型不明时按「运动 + 镜头 + 结束状态」来写，并在末尾补一句该模型的用法。

## 目标输出

一条完整提示，五段都在，外加两三句写作选择，和一句模型注意。不要拆成多条互不相关的提示。

## 步骤

1. 确认四件事里缺什么：类型、时长、主体与场景、视觉气质。已经齐了就直接写。
2. 按五段写，后一段不得推翻前一段的人物和调色。
3. 单镜用秒切片（动作 / 镜头 / 必要的可见效果）；多镜用镜切片（景别 / 构图 / 运动 / 动作）。单镜不超过约 15 秒，多镜不超过 8 镜。
4. 交付前跑硬约束。不过关就改，不要带着空词交出去。

## 五段

1. **核心主题**：3–6 个具体标签，用 `|` 隔开。从片种到气质，不要「电影感」。
2. **人物与场景**：脸（锁参考、保留瑕疵、不美颜）、服装（先写材质）、场景（风、烟、雨等正在发生的环境，不要死背景）。
3. **氛围与画质**：写真实摄影机和镜头组合，外加一条主色关系。大场面可用大画幅胶片机 + 定焦中焦；粗粝科幻用数字电影机 + 老镜头；港味 / 武侠可用漂白绕过的胶片感；人像特写用大光圈中长焦。全片只锁一种调色。
4. **镜头规则**：写清单镜还是多镜、景别与角度、以及很轻的手持浮动（像呼吸，不是剧烈摇晃）。音乐片才要配乐；其余默认只要同期声，并把关键环境声点名。
5. **分镜**：单镜按秒，多镜按镜。每一段只有一个主动作。

## 硬约束 / 禁止

- 禁止用史诗、震撼、完美、帅气、4K、高细节代替看得见的物体和动作。抽三个形容词，画不出来就删。
- 必须出现一套具体的摄影机 + 镜头，不能只写「手持」。
- 脸、服装或装备上至少两处不完美（磨损、伤痕、旧了的材质），用来锁同一主体。
- 单镜结尾禁止堆爆炸、强光、胜利定格。默认收在一个还在持续的小动作和环境细节上。
- 不写具体作品、角色、明星的名字。用户坚持要写时，正文仍给一个去名字的替代表述，并单独警告可能被模型拦截。
- 有负向栏的模型：负向用逗号分隔的名词，不要写「不要…」这种命令句。没有负向栏的模型：只写画面里应该出现的东西。
- 多镜不许每镜换一套调色。时间可以用季节、光线变化来标，室内或主光关系保持同一套。

## 输出格式

```text
核心主题：… | … | …

人物与场景
- 脸：
- 服装：
- 场景：

氛围与画质
- 机器与镜头：
- 色彩：

镜头规则
- 单镜或多镜：
- 角度：
- 浮动：手持，全程极轻、像呼吸的浮动
- 声音：不要配乐。只要同期声。……

分镜
0–3s · …
动作：
镜头：

## 选择
- …
## 模型注意
- …
```

## 质检清单

- [ ] 五段齐全，顺序未乱
- [ ] 有具体机器和镜头，有轻手持，有同期声
- [ ] 至少两处瑕疵，全片一种调色
- [ ] 结尾克制，没有效果堆叠
- [ ] 没有空词，没有作品名（或已另给替代表述并警告）
- [ ] 单镜时长和多镜数量在可生成范围内
