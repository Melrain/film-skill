# 爆款视频解析

## 何时使用

用户上传或引用参考视频，需要拆成可跟拍的**镜号列表**（画面证据 + 对白/旁白摘要），供 R7 画布「视频解析」智能体与下游续写、出图使用。

## 目标输出

- 有序镜号：`1…N`
- 每一镜：画面里**看得见的证据**（景别、主体、动作、环境）+ 对白/旁白摘要（无则写「无对白」）
- 可选：整片节奏一句话（开头如何抓人、中段推进、结尾落点）
- 对齐 R7：结果应能落到「拆解 · N 镜」卡片，而不是散文影评

## 步骤

1. 先通看时间线，标出明显切点（景别跳变、主体换人、台词段落、音乐重拍）。
2. 按切点成镜；过碎则合并同一动作连续镜，过粗则在台词/动作拐点拆开。
3. 每镜只写**画面证据**，禁止空泛形容词堆砌（如「很有氛围」而不说看见了什么）。
4. 对白写说话人可见称呼或「画外」；听不清标「听不清」。
5. 自检：换一个人只读文字能否在脑中复原该镜画面。

## 硬约束 / 禁止

- 禁止编造视频里不存在的人物、道具、台词。
- 禁止输出播放量、完播率等假数据。
- 禁止只给风格标签而不给画面。
- 单镜描述宜短；细节服务跟拍，不为炫技。

## 输出格式

按镜号列表输出（可用 Markdown）：

```text
## 节奏
（一句话）

## 镜号列表
### 镜 1
- 画面：…
- 对白：…

### 镜 2
…
```

若宿主要求 JSON，则使用：`shots: [{ index, visual, dialogue }]`，字段含义同上。

## 质检清单

- [ ] 镜号连续且覆盖片长关键段落
- [ ] 每镜有可观察画面，而非纯情绪词
- [ ] 对白与画面不矛盾
- [ ] 无假指标、无剧透式瞎编
